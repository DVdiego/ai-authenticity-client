# ai-authenticity-client
Cliente multiplataforma (Qt 6 + QML + C++) para detección de contenido IA con inferencia local vía ONNX Runtime (macOS, Windows, iOS y Android).

## Distribucion recomendada

Para compartir la aplicacion fuera del entorno de desarrollo, usar el motor nativo empaquetado.
El flujo Python debe considerarse una herramienta de desarrollo y paridad, no la opcion principal
para distribucion.
